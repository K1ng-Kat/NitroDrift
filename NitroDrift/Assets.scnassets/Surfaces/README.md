# CC0 asphalt textures

The installer uses official Poly Haven asset aerial_asphalt_01:
https://polyhaven.com/a/aerial_asphalt_01

Poly Haven makes its assets available under CC0 1.0.
The GitHub Actions workflow attempts to fetch the 1K diffuse, normal
and roughness textures and commit them into this folder automatically.
If GitHub Actions lacks write permissions, run the Python installer
locally. Procedural textures remain as a no-download fallback.
