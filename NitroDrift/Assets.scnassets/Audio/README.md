# Optional recorded engine audio

The app still uses original synthesized engine audio if this folder contains no recordings.

For a more realistic engine, add legally licensed, seamless stereo WAV loops:
- engine_low.wav (roughly 1,500–3,000 RPM)
- engine_high.wav (roughly 4,500–7,000 RPM)

Playback crossfades based on actual simulated RPM. Use matching recording levels and clean loop points. Engine samples are not bundled here.

For production realism, additional ignition, exhaust, turbo, gearshift and tire sounds would be needed. Do not copy commercial racing game recordings.
